 ## Project Headline
“Exploratory Data Analysis of Airbnb NYC 2019 with Power BI”

📑 Titles
- Airbnb Market Insights: NYC 2019
- Data Storytelling with Power BI: Airbnb Listings in New York
- Interactive Dashboard: Pricing, Demand & Host Behavior in NYC Airbnb
- EDA Case Study: Airbnb NYC 2019 Dataset

✍️ Short Description
"Built an interactive Power BI dashboard analyzing 48,000+ Airbnb listings across New York City. Explored pricing trends, demand signals, host behavior, and geospatial distribution. Delivered actionable insights through data storytelling and interactive visuals."

🎯 Purpose
- To practice end-to-end Exploratory Data Analysis (EDA) using a real-world dataset.
- To visualize Airbnb market dynamics across NYC boroughs.
- To demonstrate storytelling with data for business decision-making.
- To showcase technical expertise in Power BI, DAX, and geospatial analysis.

⚙️ Tech Stack
- Power BI → Dashboarding, DAX measures, interactive visuals
- Python (Pandas, NumPy, Seaborn) → Data cleaning & preprocessing (optional step before import)
- Tableau (optional) → Comparative visualization storytelling
- Excel/CSV → Raw dataset handling

📂 Data Source
- AB_NYC_2019 Dataset (Airbnb listings in New York City, 2019)
